🔒 Política de Privacidad - PlayGo

Última actualización: 8 de Octubre, 2024

💡 Resumen Ejecutivo: PlayGo es una aplicación de código abierto que NO recopila, almacena ni transmite ningún dato personal. Todo el procesamiento ocurre localmente en tu dispositivo.

1. Información que NO Recopilamos

PlayGo está diseñado con privacidad como prioridad fundamental. Específicamente, NO recopilamos:

  • ❌ Datos personales (nombre, email, ubicación)
  • ❌ Historial de búsquedas o reproducciones
  • ❌ Direcciones IP o información del dispositivo
  • ❌ Archivos de audio o contenido multimedia
  • ❌ Cookies o tecnologías de seguimiento
  • ❌ Datos de uso o analytics

2. Procesamiento Local

Todas las operaciones de PlayGo ocurren exclusivamente en tu dispositivo:

Función Dónde se Procesa Datos Involucrados
Búsqueda de música Tu dispositivo → YouTube Términos de búsqueda (procesados por YouTube)
Reproducción de audio 100% local Stream temporal en memoria (no se guarda)
Gestión de playlist 100% local Metadatos de canciones en memoria RAM
Comandos de usuario 100% local Comandos de terminal procesados localmente

3. Datos Técnicos y Terceros

PlayGo interactúa con servicios externos de la siguiente manera:

  • YouTube/Plataformas de Streaming: Las búsquedas se envían directamente a estas plataformas. Su uso está sujeto a sus respectivas políticas de privacidad.
  • goutubedl: Librería que facilita el acceso a contenido, opera localmente en tu dispositivo.
  • ffmpeg/ffplay: Herramientas de procesamiento de audio que funcionan 100% localmente.

4. Almacenamiento de Datos

PlayGo no escribe datos persistentes en tu dispositivo:

  • ✅ Playlists: Solo en memoria durante la ejecución
  • ✅ Archivos de audio: Streams temporales, no se guardan en disco
  • ✅ Configuración: No hay archivos de configuración persistente
  • ✅ Logs: Solo salida en consola, no se guarda en archivos

5. Transmisión de Datos

La única comunicación externa que realiza PlayGo es:

  • Consultas a YouTube: Para buscar y obtener metadatos de canciones
  • Descarga de streams: Para reproducción en tiempo real

Importante: No operamos servidores propios ni tenemos control sobre los datos que YouTube u otras plataformas puedan recopilar.

6. Código Abierto y Transparencia

PlayGo es software de código abierto, lo que significa:

  • 🔍 Transparencia total: Puedes inspeccionar todo el código fuente
  • 🔧 Verificación independiente: Cualquiera puede auditar el código
  • 🚫 Sin código oculto: No hay funcionalidades secretas
  • 📖 Documentación completa: Todo el funcionamiento está documentado

7. Seguridad

Aunque PlayGo no maneja datos sensibles, implementamos:

  • 🛡️ Procesamiento local: Minimiza riesgos de exposición
  • 🛡️ Sin almacenamiento: No hay datos que proteger
  • 🛡️ Actualizaciones regulares: Mantenemos las dependencias seguras

8. Cambios en esta Política

Notificaremos cambios significativos en esta política de privacidad:

  • 📢 Actualizando la fecha en esta página
  • 📢 Mediante releases en GitHub
  • 📢 En el archivo README del proyecto

9. Tus Derechos

Dado que no recopilamos datos personales, tienes garantías completas:

  • ✅ Control total: Tú decides cómo usar el software
  • ✅ Transparencia: Puedes ver exactamente qué hace el código
  • ✅ Eliminación: Al cerrar la aplicación, todos los datos se borran
  • ✅ Portabilidad: No hay datos que portar
