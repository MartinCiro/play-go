AVISO IMPORTANTE:

PlayGo es una herramienta educativa y de desarrollo. El uso de este software está sujeto a las leyes de derechos de autor de tu país.

1. Aceptación de los Términos

Al utilizar PlayGo ("el Software"), usted acepta cumplir con estos Términos de Servicio. Si no está de acuerdo con alguno de estos términos, no debe utilizar este software.

2. Descargo de Responsabilidad sobre Contenido Musical

PlayGo es un reproductor de música que utiliza la librería goutubedl para acceder a contenido de plataformas de streaming. Es importante entender que:

  • • El software NO almacena ni distribuye contenido con derechos de autor
  • • Todo el contenido se reproduce en tiempo real desde las fuentes originales
  • • Los archivos de audio se descargan temporalmente solo para reproducción
  • • No se permite la redistribución del contenido obtenido

3. Uso Aceptable

Usted se compromete a utilizar PlayGo únicamente para:

  • ✓ Uso personal y educativo
  • ✓ Desarrollo y pruebas de software
  • ✓ Reproducción de contenido para el que tenga derechos legales
  • ✓ Contenido de dominio público o con licencias apropiadas

4. Uso Prohibido

Queda estrictamente prohibido:

  • ✗ Distribuir contenido con derechos de autor sin autorización
  • ✗ Utilizar el software para fines comerciales ilegales
  • ✗ Modificar el software para eludir restricciones técnicas
  • ✗ Utilizar el software en jurisdicciones donde su uso sea ilegal

Política de Privacidad

Última actualización: 8 de Octubre, 2024

💡
Resumen Ejecutivo:

PlayGo es una aplicación de código abierto que NO recopila, almacena ni transmite ningún dato personal. Todo el procesamiento ocurre localmente en tu dispositivo.

1. Información que NO Recopilamos

PlayGo está diseñado con privacidad como prioridad fundamental. Específicamente, NO recopilamos:

❌ Datos personales (nombre, email, ubicación)
❌ Historial de búsquedas o reproducciones
❌ Direcciones IP o información del dispositivo
❌ Archivos de audio o contenido multimedia

2. Procesamiento Local

Todas las operaciones de PlayGo ocurren exclusivamente en tu dispositivo:

Función Dónde se Procesa Datos Involucrados
Búsqueda de música Tu dispositivo → YouTube Términos de búsqueda (procesados por YouTube)
Reproducción de audio 100% local Stream temporal en memoria (no se guarda)
Gestión de playlist 100% local Metadatos de canciones en memoria RAM

3. Código Abierto y Transparencia

PlayGo es software de código abierto, lo que significa:

🔍 Transparencia total: Puedes inspeccionar todo el código fuente
🔧 Verificación independiente: Cualquiera puede auditar el código
🚫 Sin código oculto: No hay funcionalidades secretas
📖 Documentación completa: Todo el funcionamiento está documentado
